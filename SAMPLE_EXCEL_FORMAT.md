# Sample Excel Template

This file demonstrates the expected format for the email campaign Excel file.

## Expected Format:

Column A: Email addresses
Column B: (unused - can leave blank)
Column C: Subject lines
Column D: Email body content

## Example:

```
A                              | B  | C           | D
john@example.com              | -  | Welcome     | Hello John, welcome to our service!
jane@example.com              | -  | Hello Jane  | Hi Jane, we're excited to have you!
```

## Creating the Excel File:

1. Open Excel or Google Sheets
2. Add email addresses in Column A
3. Add email subjects in Column C
4. Add email bodies in Column D (supports HTML)
5. Save as .xlsx file
6. Upload via the API
